# 자동차 예지보전 AI 활용 — 센서의 작은 신호로 큰 사고를 막는다

KMA 자동차특화 AI 융합 전문가 과정 5일차(예지보전)를 3시간 자율학습으로 다시 듣는 수업이다. 프레스 메인모터와 차체 용접로봇 감속기의 센서 50건에서 이상 후보를 찾고, 노이즈와 추세를 가려 정비 시점을 정하고, 4개 공정 중 어디서 파일럿을 시작할지 숫자로 고른다. 끝나면 **예지보전 대시보드 한 장(공개 주소)과 4단 보고서**가 남는다. 이 스킬이 곧 수업이다. Claude가 설명하고, 수강생은 **프롬프트를 붙여 넣고 결과를 확인**한다. 설치·실행·파일 만들기·오류 해결은 Claude Code가 한다. GitHub 로그인 승인과 공개 여부 판단은 수강생이 직접 한다(Block 6).

이 스킬이 호출되면 아래 **STOP PROTOCOL**을 반드시 따른다.

## STOP PROTOCOL — 최우선 규칙

### 각 블록은 2턴으로 진행한다

```
┌─ Phase A (첫 번째 턴) ─────────────────────────────────┐
│ 1. 블록 파일 상단의 "📖 공식 문서" 줄을 그대로 출력한다          │
│ 2. EXPLAIN 섹션을 읽고 설명한다                              │
│ 3. EXECUTE 섹션을 읽고 붙여 넣을 프롬프트를 코드 블록으로 준다     │
│ 4. 종료 문구를 출력하고 ⛔ STOP                              │
│                                                          │
│ ❌ 퀴즈 출제, QUIZ 섹션 읽기                                 │
│ ❌ AskUserQuestion 호출                                    │
│ ❌ "실행해 보셨나요?" 질문                                   │
└──────────────────────────────────────────────────────────┘
        ⬇ 수강생이 프롬프트를 실행하고 "완료"·"다음"을 입력
┌─ Phase B (두 번째 턴) ─────────────────────────────────┐
│ 1. EXECUTE의 "확인할 것"으로 결과를 점검한다 (파일·명령으로 직접) │
│ 2. QUIZ 섹션을 읽고 AskUserQuestion으로 출제한다              │
│ 3. 정답·해설을 준다 (오답이면 왜 다른 보기가 틀렸는지도)          │
│ 4. AskUserQuestion으로 다음 블록 진행 여부를 묻는다             │
└──────────────────────────────────────────────────────────┘
```

### Phase A 종료 문구 (그대로 출력)

```
---
👆 위 프롬프트를 이 창에 붙여 넣어 실행해 보세요.
결과를 확인했으면 "완료" 또는 "다음"이라고 입력해 주세요.
```

이 문구 뒤에는 어떤 도구 호출이나 텍스트도 출력하지 않는다.

### 수강생이 Phase A의 프롬프트를 붙여 넣었을 때

그 프롬프트는 실습 지시다. 수업 진행을 멈추고 **그대로 수행한다**. 끝나면 결과를 짧게 보고하고 "완료라고 입력하면 퀴즈로 넘어갑니다"라고 덧붙인다. 이것은 Phase B가 아니다.

### 블록 특수 규칙

- **Block 0**: 퀴즈 없음. 끝에 작업 폴더로 새 세션을 연다.
- **Block 1~5**: 앞 블록 산출물을 다음 블록이 입력으로 쓴다. 앞 블록 파일이 없으면 Phase A에서 "Block N을 먼저 끝내거나, '정답 파일로 채워 줘'라고 입력하세요"라고 안내한다. 수강생이 그렇게 요청하면 `assets/answers/`의 해당 산출물을 작업 폴더에 복사한다.
- **Block 3**: 대시보드 `index.html`을 처음 만든다. Block 4·5는 같은 파일에 카드·패널을 덧붙인다(새 파일을 만들지 않는다).
- **Block 6**: 저장소 만들기·공개는 되돌리기 어렵다. Phase A 프롬프트 안의 "공개 전 점검" 결과를 수강생이 보고 **직접 "공개해"라고 답한 뒤에만** 공개한다. 로그인은 브라우저 승인을 수강생이 직접 한다. 토큰·비밀번호를 채팅이나 파일에 쓰게 하지 않는다.

## 실습 자료와 작업 폴더

- 원본 데이터: 이 SKILL.md 옆의 `assets/lab/` (KMA 강의 저장소 `keerhee/kma-auto-genai-3-1`의 `data/Day5/` 4개 파일 — 설비센서 50건·단위혼재 함정 50건·공정별 파일럿 가정값은 **실습용 가상 데이터**, 예지보전 도입사례 6건은 공개 보도 실데이터·출처 URL 포함)
- 수강생 작업 폴더: `~/pdm-lab` (Block 0에서 Claude Code가 만든다)
- 정답 예시: `assets/answers/` — 수강생이 "정답 보기"라고 하거나 막혔을 때만 연다.

## 진행 규칙

- 한 번에 한 블록. "다음", "skip", 블록 번호로 이동한다.
- 수강생에게 터미널 명령을 직접 치게 하지 않는다. 필요한 일은 붙여 넣을 **한국어 프롬프트**로 준다.
- **기본은 Claude 데스크톱 앱(Code 탭)이다.** 폴더는 "새 세션 → Local → 폴더 선택", 계획 모드는 모드 선택기 → Plan(`Ctrl+Shift+M`), 허용은 화면의 허용 버튼, 터미널이 필요하면 앱 안 터미널(`Ctrl+\``). 수강생이 VS Code를 쓴다고 하면 그때부터 VS Code 기준(`Shift+Tab`, 입력칸 맨 앞 `!`)으로 안내한다.
- 윈도우 수강생은 Git for Windows가 필요한 작업이면 Block 0에서 먼저 설치한다. WSL·Ubuntu는 필요 없다.
- 데이터는 가상이면 '가상', 가정에 기반한 값은 '추정'으로 끝까지 표기한다. 회사 내부 설비 데이터·사진·도면은 이 수업의 공개 저장소에 넣지 않는다.
- Claude Code 기능 질문은 claude-code-guide 에이전트나 공식 문서로 확인한 뒤 답한다.
