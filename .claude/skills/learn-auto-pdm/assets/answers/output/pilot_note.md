# 파일럿 선정 메모 (실습용 가상 데이터)

시간당 정지손실만 보면 조립(2,500만원)이 가장 크지만, 연간 고장이 적고 센서 대상이 흩어져 연간 정지손실 ÷ 초기 투자 배수가 0.47배에 그친다. 같은 기준에서 프레스는 2.59배라 작게 시작해 빨리 증명하기에 맞다.

## 성과 지표
