## EXPLAIN

### 1. 오늘 쓰는 말

| 용어 | 뜻 |
|---|---|
| 작업 폴더 | 이번 수업의 모든 결과가 쌓이는 폴더 `~/pdm-lab`. 원본 데이터는 여기로 **복사**해 쓰고 원본은 건드리지 않는다 |
| CSV | 쉼표로 칸을 나눈 표 파일. 엑셀로도 열리고, Claude Code가 바로 계산할 수 있다 |
| 가상 데이터 | 실습용으로 만든 숫자. 이번 센서 50건·파일럿 가정값은 가상이고, 도입사례 6건만 공개 보도 실데이터다 |
| Claude Code | 데스크톱 앱 Code 탭에서 폴더를 열고 파일을 만들고 계산을 돌리는 AI 동료. 오늘은 원본 강의의 세 도구 역할을 혼자 한다 |

### 2. 왜 도구를 하나로 모으는가

원본 5일차 강의는 ① 환경 단계에서 도구 세 개에 역할을 나눴다.

| 일 | 원본 강의 (8시간 실습) | 이번 수업 (3시간 자율학습) |
|---|---|---|
| 예지보전 도입 사례 모으기 | Perplexity로 웹 검색 | 원본 저장소의 `도입사례_실데이터.csv`(출처 URL 포함) — 사람마다 결과가 달라지지 않게 |
| 센서 처리·이상 구간 표시 | AI 노코드 툴 | Claude Code가 계산 |
| 시계열·이상 패턴 시각화 | Google Sheets 선 차트 | Claude Code가 대시보드 `index.html`에 차트 — 그대로 공개할 수 있다 |

도구가 하나면 계산 → 차트 → 보고서 → 공개가 한 폴더 안에서 이어지고, 같은 프롬프트로 같은 결과를 다시 만들 수 있다(재현성).

### 3. 오늘의 두 설비

데이터는 2026-09-15 08:00~16:00, 20분 간격으로 설비 2대를 25번씩 잰 기록이다(가상).

- **설비A — 프레스 메인모터**: 철판을 금형으로 눌러 패널을 찍는 대형 프레스의 심장.
- **설비B — 차체 용접로봇 감속기**: 수백 대의 용접 로봇이 차체 골격을 잇는 공정의 관절.

조립 라인은 한 곳이 서면 뒤 공정이 줄줄이 선다. 라인 정지 1분 손실이 수천만 원이라는 말이 그래서 나온다. 오늘은 이 두 설비가 보내는 작은 신호를 읽는다.

## EXECUTE

아래 프롬프트를 붙여 넣으라고 안내한다. Phase A 출력 직전에 `{SKILL_DIR}`을 이 SKILL.md가 있는 실제 폴더 경로로 바꿔 보여 준다.

```
예지보전 수업 작업 폴더를 준비해 줘.

1. 내 홈 폴더 아래에 pdm-lab 폴더를 만들고, 그 안에 data, output 폴더를 만들어 줘.
2. {SKILL_DIR}/assets/lab/ 안의 CSV 4개를 pdm-lab/data/ 로 복사해 줘. 원본 파일은 수정하지 마.
3. 파일마다 행 수, 열 이름, 처음 2행을 보여 줘. 한글이 깨지면 UTF-8로 다시 읽어 줘.
4. Python 3이 있는지 확인해 줘(python, python3, py 순서로). 없으면 설치 방법을 알려 주고, 설치는 내 허락을 받은 뒤에 해.
5. Git이 있는지 확인해 줘. 없으면 마찬가지로 허락을 받고 설치해 줘.
6. 위 결과를 pdm-lab/env_check.txt 에 날짜와 함께 적어 줘.
7. 비밀번호나 토큰을 묻지 마.
```

끝나면 수강생이 직접 할 일을 안내한다.

1. 데스크톱 앱 왼쪽 위 **새 세션**을 누른다.
2. **Local**을 고르고 폴더 선택에서 홈 폴더의 `pdm-lab`을 고른다.
3. 새 세션 입력칸에 `/learn-auto-pdm`을 입력하고 "Block 0 완료"라고 말한다.
