## 가정과 확인 필요
- **시간 3시간**은 사용자가 Claude에게 맡겨 정했다. 원본은 이론 4H + 실습 4H + 인트로 2H + 보강 2H(총 12H)이므로, 이론은 블록 EXPLAIN으로 압축하고 실습 6단계와 보강 B(파일럿 선정)를 중심에 둔다. 보강 A(감시 설계)는 현장 설비 정보가 필요해 선택 블록 또는 후속 스킬 후보로 둔다(1단계에서 제안).
- 원본 실습 도구(Perplexity·노코드 툴·Google Sheets)는 learn 스킬에서 **Claude Code 한 곳**으로 대신한다. 사례 수집은 웹 검색 대신 원본 `도입사례_실데이터.csv`(출처 URL 포함)를 쓴다. 차트는 Sheets 대신 대시보드 HTML에 그린다. 이 차이는 curriculum에 이유를 적는다.
- in/s → mm/s 환산: 0.043 in/s × 25.4 = 1.09 mm/s. 정답 메모의 "실제 값" 1.08·1.1은 원본 50건 파일의 값이며, 0.043은 반올림된 기록이라 환산값과 소수 둘째 자리가 조금 다르다. 블록에서는 "환산하면 약 1.1 mm/s"로 쓴다.
- 파일럿 배수는 **연간 전체 정지손실** ÷ 초기 투자다. 예지보전으로 줄이는 몫(예: 20~30%)은 원본에서도 '추정'이므로, 블록에서 절감률을 가정으로 드러내고 배수와 구분한다.
- 도입사례 6건 중 2건(포스코 TBR, GM)은 효과 수치가 미공개다. 퀴즈·확인 수치에는 공개된 수치만 쓴다.
- `data/README.md`는 단위 혼재 파일을 50행, 도입사례를 6행으로 적었고 실제 파일과 같다.
